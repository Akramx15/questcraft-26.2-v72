# VEP UI provenance

The wrist inventory, quick-action, status HUD, creative inventory, carried-item
and contextual-container feature layer in `org.questcraft.veq` is an adapted
work derived from VisorEssentials and VisorEssentialsPlus.

- Upstream project: <https://github.com/snooped-xl/VisorEssentialsPlus>
- Retained 26.2 port reference: `work/agent-vep-perf4-host`
- License: GNU Lesser General Public License v3.0 or later

The Quest port deliberately excludes Visor's renderer, OpenXR/AtumVR bridge,
locomotion, teleport, bow, shield and server-combat code. The complete LGPLv3
text and project attribution are retained in `LICENCE.md`.
